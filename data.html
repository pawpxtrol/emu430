What this dataset is

The workbook hayvan_besleme_2024_07.xlsx contains July 2024 records of street animal feeding (hayvan besleme) associated with the Ankara Provincial Health Directorate animal-feeding reporting (Turkish: Ankara İl Sağlık Müdürlüğü, Sağlık Dairesi / ilçe sağlık operations — replace this sentence with the exact portal or announcement URL you used).

Why we chose it: It is real, public operational data, Turkey-relevant, large enough for EDA (367 rows), and it connects to urban policy and animal welfare logistics.

Objectives (data-focused): Publish a fully reproducible import and cleaning pipeline; distribute a single cleaned object feeding as feeding_clean.RData.

Import and preparation

Raw file location in this repository: data/raw/hayvan_besleme_2024_07.xlsx (copy from your Downloads if missing).

Steps (mirrors R/prepare_data.R):

  1. Read the Excel sheet with fixed column types (date + text + numeric) so Turkish headers do not depend on janitor transliteration.
  2. Rename columns to ASCII snake_case: tarih, ilce, mahalle_sokak, besleme_noktasi_sayisi, mama_text, arac_text, personel_text.
  3. Trim extra spaces in ilce and mahalle_sokak (the raw file contains values like "GÖLBAŞI " with a trailing space).
  4. Parse food mass: extract numeric kg from strings such as "84 KG" → mama_kg.
  5. Parse vehicles: "-" → missing; "Y3" (typo) → 3; otherwise parse as number.
  6. Parse personnel: "-" → missing; otherwise parse as number.
  7. Save feeding to data/feeding_clean.RData.

## Import and preparation

**Raw file location in this repository:** `data/raw/hayvan_besleme_2024_07.xlsx` (copy from your Downloads if missing).

**Steps (mirrors `R/prepare_data.R`):**

1. **Read** the Excel sheet with fixed column types (date + text + numeric) so Turkish headers do not depend on `janitor` transliteration.
2. **Rename** columns to ASCII snake_case: `tarih`, `ilce`, `mahalle_sokak`, `besleme_noktasi_sayisi`, `mama_text`, `arac_text`, `personel_text`.
3. **Trim** extra spaces in `ilce` and `mahalle_sokak` (the raw file contains values like `"GÖLBAŞI "` with a trailing space).
4. **Parse food mass:** extract numeric **kg** from strings such as `"84 KG"` → `mama_kg`.
5. **Parse vehicles:** `"-"` → missing; `"Y3"` (typo) → **3**; otherwise parse as number.
6. **Parse personnel:** `"-"` → missing; otherwise parse as number.
7. **Save** `feeding` to `data/feeding_clean.RData`.
