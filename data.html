What this dataset is

This site analyzes monthly street-animal feeding (hayvan besleme) records from Ankara Büyükşehir Belediyesi Sağlık Dairesi. Each row is one neighborhood-day of operations across Ankara’s districts (ilçeler).

We combined eleven monthly Excel workbooks spanning July 2024 through June 2025 into a single tidy dataset:

  • 2024: July, September, October, November, December
  • 2025: January, February, March, April, May, June

Why we chose it: real, public operational data; Turkey-relevant; large enough for time-series and cross-district EDA; and it touches urban policy and animal welfare logistics — a topic with current public-discourse relevance.

Objectives (data-focused):

  1. Publish a reproducible pipeline from many raw .xlsx files to a single tidy object feeding.
  2. Make the cleaned dataset publicly available as feeding_clean.RData.
  3. Document data-quality issues (mixed date formats, text-encoded numbers, coded missing values, typos, source outliers).

Accomplishments

  • Combined 11 monthly workbooks (≈ 3,700+ neighborhood-day rows) into one tibble feeding.
  • Standardized district / neighborhood labels (trimmed stray spaces such as "GÖLBAŞI ").
  • Parsed mixed date formats — column 1 is read as a native Excel date where possible; when that is missing (e.g. March 2025 string cells like "1.03.2025"), we fill from the text column with parse_date_from_text() (Excel serials, lubridate, explicit formats).
  • Parsed text-encoded dry-food amounts into numeric mama_kg (e.g. "84 KG" → 84).
  • Normalized vehicle / personnel fields: Y3 → 3, - → missing, blank → missing.
  • Added derived columns yil, ay, yil_ay so the analysis page can compare across months.
  • Kept a source_file column for traceability back to each monthly workbook.

Source and citation

The raw files are monthly publications from Ankara Büyükşehir Belediyesi Sağlık Dairesi (“Sağlık Dairesi Hayvan Besleme Verileri”). The files are shared on the belediye website https://seffaf.ankara.bel.tr/.

Import and preparation

Raw files location in this repository: data/raw/hayvan_besleme_YYYY_MM.xlsx (one workbook per month).

Pipeline (mirrors R/prepare_data.R):

  1. Auto-discover every file under data/raw/ matching hayvan_besleme_*.xlsx.
  2. Read each workbook twice for column 1: native Excel date (covers most months) plus a parallel text pass so we can recover string-encoded dates (e.g. March 2025’s "1.03.2025") and numeric Excel serials if a sheet is ever exported as plain numbers.
  3. Merge the two passes: use as.Date() on the date column; where it is still NA, fill from the text column via parse_date_from_text().
  4. Rename the seven source columns to ASCII snake_case: tarih, ilce, mahalle_sokak, besleme_noktasi_sayisi, mama_kg (via mama_text), arac_sayisi, personel_sayisi, plus metadata source_file.
  5. Trim extra spaces in ilce and mahalle_sokak.
  6. Parse food mass with readr::parse_number() (Turkish decimal comma) from the mama text field.
  7. Parse vehicles: "-" → NA; "Y3" (typo) → 3; otherwise numeric.
  8. Parse personnel: "-" → NA; otherwise numeric.
  9. Combine with purrr::map_dfr(), drop rows whose date failed to parse, add yil / ay / yil_ay, and save feeding to data/feeding_clean.RData.

## What this dataset is

This site analyzes **monthly street-animal feeding (`hayvan besleme`) records** from **Ankara Büyükşehir Belediyesi Sağlık Dairesi**. Each row is one **neighborhood-day** of operations across Ankara's districts (*ilçeler*).

We combined **eleven monthly Excel workbooks** spanning **July 2024 through June 2025** into a single tidy dataset:

- 2024: July, September, October, November, December
- 2025: January, February, March, April, May, June

**Why we chose it:** real, public operational data; **Turkey-relevant**; large enough for time-series and cross-district EDA; and it touches **urban policy** and **animal welfare** logistics — a topic with current public-discourse relevance.

**Objectives (data-focused):**

1. Publish a **reproducible** pipeline from many raw `.xlsx` files to a single tidy object `feeding`.
2. Make the cleaned dataset publicly available as **`feeding_clean.RData`**.
3. Document **data-quality issues** (mixed date formats, text-encoded numbers, coded missing values, typos, source outliers).

## Accomplishments

- Combined **11 monthly workbooks** (≈ 3,700+ neighborhood-day rows) into one tibble `feeding`.
- **Standardized** district / neighborhood labels (trimmed stray spaces such as `"GÖLBAŞI "`).
- **Parsed mixed date formats** — column 1 is read as a native Excel **`date`** where possible; when that is missing (e.g. **March 2025** string cells like `"1.03.2025"`), we fill from the text column with `parse_date_from_text()` (Excel serials, `lubridate`, explicit formats).
- **Parsed** text-encoded dry-food amounts into numeric **`mama_kg`** (e.g. `"84 KG"` → `84`).
- **Normalized vehicle / personnel** fields: **`Y3` → 3**, **`-` → missing**, blank → missing.
- Added derived columns **`yil`**, **`ay`**, **`yil_ay`** so the analysis page can compare across months.
- Kept a **`source_file`** column for traceability back to each monthly workbook.

## Source and citation

The raw files are monthly publications from **Ankara Büyükşehir Belediyesi Sağlık Dairesi** (“Sağlık Dairesi Hayvan Besleme Verileri”). The files are shared on the belediye website **<https://seffaf.ankara.bel.tr/>**.

## Import and preparation

**Raw files location in this repository:** `data/raw/hayvan_besleme_YYYY_MM.xlsx` (one workbook per month).

**Pipeline (mirrors `R/prepare_data.R`):**

1. **Auto-discover** every file under `data/raw/` matching `hayvan_besleme_*.xlsx`.
2. **Read each workbook twice for column 1:** native Excel **`date`** (covers most months) plus a parallel **text** pass so we can recover **string-encoded dates** (e.g. March 2025’s `"1.03.2025"`) and **numeric Excel serials** if a sheet is ever exported as plain numbers.
3. **Merge** the two passes: use `as.Date()` on the date column; where it is still `NA`, fill from the text column via `parse_date_from_text()`.
4. **Rename** the seven source columns to ASCII snake_case: `tarih`, `ilce`, `mahalle_sokak`, `besleme_noktasi_sayisi`, `mama_kg` (via `mama_text`), `arac_sayisi`, `personel_sayisi`, plus metadata `source_file`.
5. **Trim** extra spaces in `ilce` and `mahalle_sokak`.
6. **Parse food mass** with `readr::parse_number()` (Turkish decimal comma) from the mama text field.
7. **Parse vehicles:** `"-"` → `NA`; `"Y3"` (typo) → `3`; otherwise numeric.
8. **Parse personnel:** `"-"` → `NA`; otherwise numeric.
9. **Combine** with `purrr::map_dfr()`, drop rows whose date failed to parse, add `yil` / `ay` / `yil_ay`, and **save** `feeding` to `data/feeding_clean.RData`.
